# Policy gradient HVAC
Matlab Implementation of a Policy gradient algorithm for Linear systems. The algorithm has been implemented for an HVAC system of a room that is affected by disturbances due to human occupancy and outside weather [1]. The Policy gradient algorithm closely follows Data-Enabled Policy Optimization (DeePO) [2], but has been extended with a learned feedforward term to account for disturbances. 

References:
1) Misra, R., and Melgaard, S.P., Data-driven feedforward policy gradient for room temperature control (2026)
2) Zhao, F., Dörfler, F., Chiuso, A. and You, K. Data-Enabled Policy Optimization for Direct Adaptive Learning of the LQR. IEEE Transactions On Automatic Control. 70, 7217-7232 (2025)
